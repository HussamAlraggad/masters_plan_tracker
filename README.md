# masters_plan_tracker

Tracking my master's plan

## My initial plan

I want to build a system that tracks my master's degree progress in terms of my plan for the degree, I have the courses plan with me, I want to import it to the proposed system, then the system displays the plan in creative way, the tracking contiues further here, I will be visiting this system once in a while and either update the course status {Pending, Registered, Passed, or Failed}, I want a suggesting system that hints to the best options to choose for the next semester, I will help this system by providing the next semester date, how many course do I wish to register. We can expand it further in any further iteration, the current plan is enough to initiate the project and test it in real time.

### Helpful links, resources

- Courses page (جريدة المواد): https://hu.edu.jo/unitCenter/class_a.aspx?t=0&unitid=40000000
- All master's non-thesis courses share this exact prefix in their CourseID: 1210037
- All master's thesis courses follow this pattern:
    1- X1003799 as the course id where X = credit hours:
        1- 91003799 (9 hrs)
        2- 61003799 (6 hrs)  
        3- 31003799 (3 hrs)

### The tech stack I think of

I thinking about the normal usual stack: Next.js, Pocketbase, and I got some skills recently setup in OpenCode that I would love to try out for the UI and maybe the UX too.

### The UI I imagine

I want a fully dark theme, no light theme switch, a simple UI, minimal navigation, not so many option in the UI, the nav bar can be either discarded or holds the logo and a couple of links only...

Glassy, frosty, transparent theme style is preffered, minimal colors too, if possible everything floats or kinda orbits as if we're in the outer space.

One page is better than navigating to multiple pages.
